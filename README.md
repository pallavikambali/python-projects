# 🐍 Python Creative Projects

A collection of Python visual projects built using the `turtle` module.
All projects are beginner-friendly and focus on animations, games, and mathematical art.

---

## 🎨 Projects

| Project | Description |
|---|---|
| 🌸 Nebula Heart | Glowing animated heart with 400 particles and color cycling |
| 🌺 Aurora Bloom | Recursive fractal flower with rainbow colors |
| 🐍 Snake Game | Playable snake game with score and high score tracker |
| ✨ Luminous Art | Spiral fractal art with shifting hues |
| 🎨 Mandala Art | Rotating rainbow mandala pattern |
| 🎆 Fireworks | Animated fireworks with gravity and particle effects |
| ⏰ Analog Clock | Live working clock showing real time |
| 🦋 Butterfly Curve | Mathematical butterfly curve with glow effect |
| 🌊 Ocean Waves | Animated night ocean scene with stars and moon |

---

## 🛠️ Requirements

- Python 3.13+
- No extra libraries needed — all built with Python's built-in `turtle` module

---

## 🚀 How to Run

1. Install Python from [python.org](https://python.org)
2. Clone this repository:git clone https://github.com/pallavikambali/python-projects.git
3. Run any project: py analog_clock.py
